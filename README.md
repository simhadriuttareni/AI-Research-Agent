# AI Research Agent

An autonomous, multi-agent system that performs deep research on any topic without human intervention.

## Features

- 🔍 **Multi-Agent Collaboration**: 7 specialized agents working together
- 🌐 **Web Search Integration**: Tavily API and DuckDuckGo
- 📚 **Academic Search**: ArXiv integration
- 🗄️ **Vector Database**: ChromaDB for semantic search
- 📝 **Report Generation**: Professional research reports with citations
- ✅ **Self-Correction**: Reviewer agent ensures quality
- 📊 **Production Ready**: Docker, PostgreSQL, Redis, FastAPI

## Quick Start

### Prerequisites

- Python 3.11+
- Docker and Docker Compose
- API Keys: Groq, Tavily
